Privacy Policy

KyivNotKiev Research · Last updated: July 2026

What we collect

This website does not collect, store, or process any personal data from visitors. We do not use cookies, analytics trackers, or advertising scripts.

YouTube API Services

Our research pipeline uses the YouTube API Services to search for publicly available video metadata (video titles, publication dates, channel names, and view counts). We do not access, store, or display any user data, comments, private videos, or video content.

By using this site, you also agree to be bound by the Google Privacy Policy.

Data we store from YouTube

For each video found via search, we store only:

  • Video ID
  • Title
  • Publication date
  • Channel name
  • View count

This metadata is used exclusively to compute aggregate spelling adoption ratios (e.g., percentage of videos using "Kyiv" vs "Kiev"). No individual video data is displayed on the website — only aggregate statistics.

No commercial use

This is a non-commercial academic research project. We do not sell data, display advertising, or charge users.

Open data

Aggregate research data is published on HuggingFace. No personal or user-identifiable information is included.
