#KyivNotKiev Research

YouTube API Usage Report · Computational Linguistics Study of Ukrainian Toponym Adoption

This study measures how English-language media adopted Ukrainian place name spellings (e.g., "Kyiv" vs "Kiev") across 9 independent sources including YouTube. The campaign was launched by Ukraine's Ministry of Foreign Affairs in 2018.

API Pipeline

# 1. Search for each spelling variant per year search.list(q="Kyiv", publishedAfter="2022-01-01", type="video") # 2. Get metadata in batch (50 videos per call, 1 unit) videos.list(part="snippet,statistics", id="id1,id2,...") # 3. Classify variant from title → compute adoption ratio

We store only: video_id, title, publishedAt, viewCount, channelTitle. No video content, comments, or user data.
